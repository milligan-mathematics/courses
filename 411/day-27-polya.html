How these work. Each walk-through takes one problem through Pólya’s four phases. You answer one step at a time and get feedback right away; when something isn’t right, read why and try again. Hints are there when you ask for them. Your place is saved in this browser, so you can stop and come back.

Something new: the point \(a\) is left out. Definition 8.3.1 tests only \(0 < |x - a| < \delta\), so the function doesn’t need a value at \(a\), and the limit never looks there. Some steps ask you to type \(\delta\) as a formula in \(\varepsilon\) (and in \(a\), when the problem has one). The page then plays the opponent: it names challenges from \(\varepsilon = 10\) down to \(\varepsilon = 0.000001\), and for each one it hunts for an \(x\) within your \(\delta\) of \(a\) whose value lands outside the band around the limit. Any \(\delta\) that survives is right, not only the one in the model proof. The page samples many points, so passing is strong evidence, not a proof. If yours fails, you’ll see the challenge and the \(x\) that beat it.

Problem 8.3.10 has a picture of the unit circle. These walk-throughs describe it in words and walk through the reasoning; they don’t draw anything.

The walk-throughs end in full proofs, so the proof you bring to class should still be your own, in your own words.

Pólya walk-through · Problem 8.3.3

The hole at \(x = a\)

Problem 8.3.3. Use the definition of a limit to verify that \(\displaystyle\lim_{x\to a}\frac{x^2-a^2}{x-a}=2a\).

Goal: Use Definition 8.3.1 for a quotient with no value at \(a\): simplify away from \(a\), then name a \(\delta\) that works for every \(a\). Example 8.3.2 is the case \(a = 1\) of this problem, for \(\frac{x^2-1}{x-1}\). Problem 8.3.4 has two more limits of this kind, where the simplified quotient has to be bounded before \(\delta\) can be named.

Pólya walk-through · Problem 8.3.4

Bound the quotient, then name \(\delta\)

Problem 8.3.4. Use the definition of a limit to verify each of the following limits.
(a) \(\displaystyle\lim_{x\to 1}\frac{x^3-1}{x-1}=3\)
(b) \(\displaystyle\lim_{x\to 1}\frac{\sqrt{x}-1}{x-1}=\frac12\)

Goal: Bound \(|f(x) - L|\) above by a simple multiple of \(|x - 1|\), then name a \(\delta\) that makes the bound less than \(\varepsilon\). Part (a) needs one more idea than part (b). It uses the bounding habit of Day 17’s 6.1.6, now on a function, and the domain of \(\sqrt{x}\) that Day 23 handled for continuity.

Pólya walk-through · Problem 8.3.7

Limit laws, by translation

Problem 8.3.7. Prove parts (b) and (c) of Theorem 8.3.6. The theorem: suppose \(\displaystyle\lim_{x\to a}f(x)=L\) and \(\displaystyle\lim_{x\to a}g(x)=M\). Then (b) \(\displaystyle\lim_{x\to a}\bigl(f(x)\cdot g(x)\bigr)=L\cdot M\), and (c) \(\displaystyle\lim_{x\to a}\frac{f(x)}{g(x)}=\frac{L}{M}\), provided \(M\ne 0\) and \(g(x)\ne 0\) for \(x\) sufficiently close to \(a\) (but not equal to \(a\)).

Goal: Translate each function limit into a statement about sequences with Corollary 8.3.5, apply the sequence theorem, and translate back. Part (c) needs one hypothesis the sequences must earn. Part (b) is the product rule for sequences (Theorem 6.2.6, Day 19) and part (c) the quotient rule (Theorem 6.2.12, Day 20). Their proofs are already done; this problem is about borrowing them.

Pólya walk-through · Problem 8.3.9

The squeeze, for functions

Problem 8.3.9. Prove Theorem 8.3.8, the Squeeze Theorem for functions. Suppose \(f(x) \le g(x) \le h(x)\) for \(x\) sufficiently close to \(a\) (but not equal to \(a\)). If \(\displaystyle\lim_{x\to a}f(x) = L = \lim_{x\to a}h(x)\), then \(\displaystyle\lim_{x\to a}g(x) = L\) also.

Goal: Turn the squeeze for functions into the squeeze for sequences, using Corollary 8.3.5 on the two outside functions and on the middle one at the end. Theorem 6.2.15, the Squeeze Theorem for sequences, does the work (Day 20). Problem 8.3.10 uses this theorem for \(\frac{\sin x}{x}\).

Pólya walk-through · Problem 8.3.10

Areas in the unit circle

Problem 8.3.10. Use the fact that \(\text{area}(\Delta OAC) < \text{area}(\text{sector } OAC) < \text{area}(\Delta OAB)\) to show that if \(0 < x < \frac{\pi}{2}\), then \(\cos x < \frac{\sin x}{x} < 1\). Use the fact that all of these functions are even to extend the inequality for \(-\frac{\pi}{2} < x < 0\), and use the Squeeze Theorem to show \(\displaystyle\lim_{x\to 0}\frac{\sin x}{x} = 1\).

Goal: Turn three areas into two inequalities for \(\frac{\sin x}{x}\), extend them by evenness, and squeeze. The step that needs care is the direction of each inequality. This is the limit the reading began with: the slope of \(\sin x\) at \(0\) is \(\lim_{x\to 0}\frac{\sin x}{x}\). It uses Problem 8.2.14 (cosine is continuous, Day 26) and Problem 8.3.9.
