How these work. Each walk-through takes one exercise through Pólya’s four phases. You answer one step at a time and get feedback right away; when something isn’t right, read why and try again. Hints are there when you ask for them. Your place is saved in this browser, so you can stop and come back.

The walk-throughs end in full solutions, so the work you present in class should still be your own, in your own words.

Pólya walk-through · Exercise 6.5.7

Euler’s Theorem for 4 and 15

Exercise 6.5.7. Verify Euler’s Theorem for \(n = 15\) and \(a = 4\).

Goal: Check the hypotheses, then compute \(4^{\phi(15)} \bmod 15\) without multiplying out the whole power. It is an application of Euler’s Theorem (Theorem 6.3.2), with \(\phi(15) = |U(15)|\) (Theorem 6.3.1). The look-back uses Corollary 6.2.3: the order of \(4\) divides \(|U(15)| = 8\).

Pólya walk-through · Exercise 6.5.8

No square roots of −1 when p = 4n + 3

Exercise 6.5.8. Use Fermat’s Little Theorem to show that if \(p = 4n + 3\) is prime, there is no solution to the equation \(x^2 \equiv -1 \pmod{p}\).

Goal: Turn the congruence \(x^2 \equiv -1\) into a statement about the power \(x^{p-1}\), and see that the same power has to be both \(1\) and \(-1\). It uses Fermat’s Little Theorem (Theorem 6.3.3) with the exponent \(p - 1\) from Section 6.3. The look-back connects to Corollary 6.2.3 (the order of an element divides \(|U(p)|\)) applied to \(U(p)\).

Pólya walk-through · Exercise 6.5.15

Same cycle structure, same conjugacy class

Exercise 6.5.15. The cycle structure of a permutation \(\sigma\) is the unordered list of the sizes of the cycles in its cycle decomposition. For example, \(\sigma = (1\,2)(3\,4\,5)(7\,8)(9)\) has cycle structure \((2,3,2,1)\), which can also be written \((1,2,2,3)\). Show that any two permutations \(\alpha, \beta \in S_n\) have the same cycle structure if and only if there exists a permutation \(\gamma\) such that \(\beta = \gamma\alpha\gamma^{-1}\). If \(\beta = \gamma\alpha\gamma^{-1}\) for some \(\gamma \in S_n\), then \(\alpha\) and \(\beta\) are conjugate.

Goal: Prove an “if and only if” by proving both halves, and use Theorem 6.2.8 one cycle at a time. It builds on Theorem 6.2.8, which handles two single cycles. Here the same idea is applied to every cycle of a permutation at once, with fixed points counted as cycles of length 1.

Pólya walk-through · Exercise 6.5.18

Index two: left and right cosets agree

Exercise 6.5.18. If \([G : H] = 2\), prove that \(gH = Hg\) for all \(g \in G\).

Goal: Split into the case \(g \in H\) and the case \(g \notin H\), and use the two cosets to see that gH and Hg are both the part of \(G\) outside \(H\). It uses the partition of \(G\) into left cosets (Theorem 6.1.4), the same for right cosets (Remark 6.1.5), and the equal number of left and right cosets (Theorem 6.1.8). The index is defined in Section 6.1.

Pólya walk-through · Exercise 6.5.22

The product formula for φ(n)

Exercise 6.5.22. Let \(n = p_1^{e_1} p_2^{e_2} \cdots p_k^{e_k}\), where \(p_1, p_2, \ldots, p_k\) are distinct primes. Prove that \(\phi(n) = n \left(1 - \frac{1}{p_1}\right)\left(1 - \frac{1}{p_2}\right)\cdots\left(1 - \frac{1}{p_k}\right)\).

Goal: Count the numbers from 1 to \(n\) that share a factor with \(n\), without listing them, and see that the count matches the product. It uses the definition of \(\phi\) from Section 6.3 and the fact that \(|U(n)| = \phi(n)\) (Theorem 6.3.1). The counting uses unique factorization (Theorem 2.2.7) to see which numbers are divisible by several distinct primes.
