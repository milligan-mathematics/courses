# §15.3: The Fundamental Theorem for Line Integrals

Evaluating a line integral the long way means parametrizing the path, substituting, and integrating, and a messy path makes that messy. Now recall the Fundamental Theorem of Calculus: $$\int_a^b f'(x)\,dx = f(b) - f(a)$$. You never needed to know what $$f'$$ did *between* $$a$$ and $$b$$, only what $$f$$ was at the two ends. There is a version of that theorem for line integrals, and it applies exactly to the fields that are gradients.

This section answers three linked questions. How do you evaluate $$\int_C\mathbf{F}\cdot d\mathbf{r}$$ in one subtraction? When does the answer depend only on the endpoints? And how can you tell, quickly, whether a given field is conservative and find its potential?

By the end of this section you should be able to:

1. State and use the Fundamental Theorem for Line Integrals.
2. Explain path independence, and its connection with closed-path integrals and conservative fields.
3. Use the component test to decide whether a field is conservative.
4. Find a potential function for a conservative field in two or three variables.

### The theorem

**Theorem (Fundamental Theorem for Line Integrals).** Let $$C$$ be a smooth curve $$\mathbf{r}(t)$$, $$a\le t\le b$$. If $$f$$ is differentiable and $$\nabla f$$ is continuous on an open region containing $$C$$, then

$$\int_C \nabla f\cdot d\mathbf{r} = f\bigl(\mathbf{r}(b)\bigr) - f\bigl(\mathbf{r}(a)\bigr).$$

**Why it is true.** By definition, $$\int_C\nabla f\cdot d\mathbf{r} = \int_a^b\nabla f(\mathbf{r}(t))\cdot\mathbf{r}'(t)\,dt$$. The integrand is

$$\frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt} + \frac{\partial f}{\partial z}\frac{dz}{dt},$$

and that is exactly what the Chain Rule says $$\dfrac{d}{dt}f(\mathbf{r}(t))$$ is. So the integral is $$\int_a^b\dfrac{d}{dt}f(\mathbf{r}(t))\,dt$$, and the ordinary Fundamental Theorem of Calculus finishes it: $$f(\mathbf{r}(b)) - f(\mathbf{r}(a))$$.

The potential function plays the role of the antiderivative, and the answer depends only on the **initial point** and **terminal point**.

> **Worked example.** Evaluate $$\displaystyle\int_C\mathbf{F}\cdot d\mathbf{r}$$ for $$\mathbf{F}(x,y) = \langle ye^{xy},\ xe^{xy}\rangle$$, where $$C$$ is any smooth curve from $$(0,1)$$ to $$(2,0)$$.
>
> *Check.* $$P_y = e^{xy} + xye^{xy}$$ and $$Q_x = e^{xy} + xye^{xy}$$. They agree, so $$\mathbf{F}$$ looks conservative.
>
> *Find a potential.* From $$f_x = ye^{xy}$$, integrate in $$x$$: $$f = e^{xy} + g(y)$$. Then $$f_y = xe^{xy} + g'(y)$$ must equal $$Q = xe^{xy}$$, so $$g' = 0$$. Take $$f(x,y) = e^{xy}$$.
>
> *Apply the theorem.* $$\int_C\mathbf{F}\cdot d\mathbf{r} = f(2,0) - f(0,1) = e^0 - e^0 = 0.$$

> **Worked example.** The field $$\mathbf{F}(x,y,z) = \langle yz, xz, xy\rangle$$ from §15.2 satisfies $$P_y = z = Q_x$$, $$P_z = y = R_x$$, $$Q_z = x = R_y$$, and $$f(x,y,z) = xyz$$ is a potential ($$f_x = yz$$, $$f_y = xz$$, $$f_z = xy$$). So the work along the straight segment from $$A = (1,0,0)$$ to $$B = (0,2,0)$$ is $$f(0,2,0) - f(1,0,0) = 0 - 0 = 0$$.
>
> Look back at §15.2: the work along $$\langle t^2,t^3,t\rangle$$ from $$(0,0,0)$$ to $$(1,1,1)$$ took a page of work and came out $$1$$. The theorem gives it at once: $$f(1,1,1) - f(0,0,0) = 1$$.

### Path independence

A line integral $$\int_C\mathbf{F}\cdot d\mathbf{r}$$ is **path independent** if its value is the same for every path in the domain that starts at $$A$$ and ends at $$B$$, for every pair $$A$$, $$B$$. A **closed path** starts and ends at the same point, and $$\oint_C$$ denotes an integral around one.

**The theorem above says: if $$\mathbf{F}$$ is conservative, then its line integrals are path independent.** Two more facts tie these ideas together.

**Path independence $$\Longleftrightarrow$$ every closed-path integral is zero.**

- *($$\Rightarrow$$)* Split a closed path $$C$$ at two points $$P$$ and $$Q$$ into $$C_1$$ (from $$P$$ to $$Q$$) and $$C_2$$ (from $$Q$$ back to $$P$$). Reversing a path flips the sign, so $$\oint_C = \int_{C_1} + \int_{C_2} = \int_{C_1} - \int_{-C_2}$$, where $$-C_2$$ also runs from $$P$$ to $$Q$$. Path independence says the two integrals on the right are equal, so $$\oint_C\mathbf{F}\cdot d\mathbf{r} = 0$$.
- *($$\Leftarrow$$)* Let $$C_1$$ and $$C_2$$ be two paths from $$A$$ to $$B$$. Then $$C_1$$ followed by $$-C_2$$ is a closed path, so $$\int_{C_1} - \int_{C_2} = 0$$.

**Path independence $$\Longrightarrow$$ conservative** (on an open, connected region). Fix a starting point $$A$$ and define $$f(B) = \int_A^B\mathbf{F}\cdot d\mathbf{r}$$; path independence is exactly what makes this a well-defined function of $$B$$. To find $$f_x$$, go to $$(x+\Delta x,y,z)$$ by first reaching $$(x,y,z)$$ and then following the horizontal segment $$\langle t,y,z\rangle$$. Then

$$\frac{f(x+\Delta x,y,z) - f(x,y,z)}{\Delta x} = \frac1{\Delta x}\int_x^{x+\Delta x}P(t,y,z)\,dt \longrightarrow P(x,y,z)$$

by the Fundamental Theorem of Calculus. The same argument gives $$f_y = Q$$ and $$f_z = R$$, so $$\nabla f = \mathbf{F}$$.

So for a field on an open connected region, **conservative**, **path independent**, and **zero around every closed path** all mean the same thing.

### The component test

If $$\mathbf{F} = \nabla f$$ then mixed partials of $$f$$ agree (Clairaut), so:

- in the plane, $$\dfrac{\partial P}{\partial y} = \dfrac{\partial Q}{\partial x}$$;
- in space, $$\dfrac{\partial P}{\partial y} = \dfrac{\partial Q}{\partial x}$$, $$\dfrac{\partial P}{\partial z} = \dfrac{\partial R}{\partial x}$$, and $$\dfrac{\partial Q}{\partial z} = \dfrac{\partial R}{\partial y}$$.

If the components have continuous first partials on a **simply connected** region (one where every closed loop can be shrunk to a point without leaving it; the plane is, the plane with the origin removed is not), then these equations are also *sufficient*. Where the region has a hole the test can pass and the field still fail to be conservative, so watch the domain.

> **Worked example.** Is $$\mathbf{F}(x,y) = \langle y^2,\ x^2\rangle$$ conservative?
>
> $$P_y = 2y$$ but $$Q_x = 2x$$. These are not equal (for example at $$(0,1)$$ they are $$2$$ and $$0$$), so $$\mathbf{F}$$ is **not conservative**. And you can see path dependence directly. From $$(0,0)$$ to $$(1,1)$$, the straight line $$y=x$$ gives $$\int_0^1 2x^2\,dx = \tfrac23$$. Along the $$x$$-axis to $$(1,0)$$ and then straight up, the first leg contributes $$0$$ and the second contributes $$\int_0^1 1\,dy = 1$$.

> **Worked example.** Is $$\mathbf{F}(x,y,z) = \langle yz,\ xz,\ x^2y\rangle$$ conservative?
>
> $$P_y = z = Q_x$$, so far so good. But $$P_z = y$$ while $$R_x = 2xy$$. One failed equation is enough: **not conservative.**

### Finding a potential function

If the test passes, build $$f$$ one variable at a time: integrate $$P$$ in $$x$$, which leaves an unknown "constant" $$g(y,z)$$; match $$f_y$$ with $$Q$$ to find $$g$$ up to a function of $$z$$; match $$f_z$$ with $$R$$ to finish.

> **Worked example.** Show that $$\mathbf{F}(x,y,z) = \langle 2xz,\ \sin z,\ x^2 + y\cos z\rangle$$ is conservative and find a potential.
>
> *Test.* $$P_y = 0 = Q_x$$; $$P_z = 2x = R_x$$; $$Q_z = \cos z = R_y$$. All three hold.
>
> *Step 1.* $$f = \int 2xz\,dx = x^2z + g(y,z)$$.
>
> *Step 2.* $$f_y = g_y$$ must equal $$Q = \sin z$$, so $$g = y\sin z + h(z)$$ and $$f = x^2z + y\sin z + h(z)$$.
>
> *Step 3.* $$f_z = x^2 + y\cos z + h'(z)$$ must equal $$R = x^2 + y\cos z$$, so $$h' = 0$$.
>
> A potential is $$f(x,y,z) = x^2z + y\sin z$$. For instance, the work along any path from $$(0,0,0)$$ to $$(1,2,\pi/2)$$ is $$f(1,2,\pi/2) - f(0,0,0) = \tfrac\pi2 + 2$$.

> **Worked example.** Evaluate $$\displaystyle\int_C\mathbf{F}\cdot d\mathbf{r}$$ for $$\mathbf{F}(x,y) = \langle 2x\cos y,\ -x^2\sin y\rangle$$, where $$C$$ is $$\mathbf{r}(t) = \langle t^2,\pi t\rangle$$, $$0\le t\le1$$.
>
> $$P_y = -2x\sin y = Q_x$$, so the field passes the test. Integrating $$P$$ in $$x$$ gives $$f = x^2\cos y + g(y)$$, and $$f_y = -x^2\sin y + g'(y) = Q$$ forces $$g' = 0$$. Take $$f = x^2\cos y$$. The curve starts at $$\mathbf{r}(0) = (0,0)$$ and ends at $$\mathbf{r}(1) = (1,\pi)$$, so
>
> $$\int_C\mathbf{F}\cdot d\mathbf{r} = f(1,\pi) - f(0,0) = 1\cdot(-1) - 0 = -1.$$

> **Worked example.** Evaluate $$\displaystyle\int_C\mathbf{F}\cdot d\mathbf{r}$$ for $$\mathbf{F}(x,y,z) = \langle e^z,\ 1,\ xe^z\rangle$$ where $$C$$ goes from $$(0,1,0)$$ to $$(1,1,0)$$ to $$(1,0,0)$$ to $$(1,0,\ln2)$$ (three straight segments).
>
> The test passes ($$P_y = Q_x = 0$$, $$P_z = R_x = e^z$$, $$Q_z = R_y = 0$$), and $$f = xe^z + y$$ is a potential. We never need the three segments, only the two ends of the path:
>
> $$\int_C\mathbf{F}\cdot d\mathbf{r} = f(1,0,\ln2) - f(0,1,0) = (1\cdot2 + 0) - (0 + 1) = 1.$$

### Practice & reflection

1. Explain why the Fundamental Theorem for Line Integrals is the "same theorem" as the Fundamental Theorem of Calculus. What plays the role of the antiderivative? What plays the role of the interval?
2. Someone hands you $$\int_C\mathbf{F}\cdot d\mathbf{r}$$ along a complicated path and asks for the value. What is the first thing you should check, and why?
3. If $$\mathbf{F}$$ is conservative and $$C$$ is a closed loop, what is $$\oint_C\mathbf{F}\cdot d\mathbf{r}$$? Which of the equivalent statements about conservative fields does that use?
4. In a field that is *not* conservative, two particular paths from $$A$$ to $$B$$ might still give the same work by coincidence. Why does that not make the field path independent?
5. The plane is simply connected and the plane with the origin removed is not. Why might the second fact make you cautious about concluding "conservative" from the component test?
