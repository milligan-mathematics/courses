How these work. Each walk-through takes one problem through Pólya’s four phases. You answer one step at a time and get feedback right away; when something isn’t right, read why and try again. Hints are there when you ask for them. Your place is saved in this browser, so you can stop and come back.

Something new: typed formulas. Some steps ask you to type a number, or a formula in \(n\). The page checks what you type at several values, so any correct formula is right, not only the one in the model. When your answer matches a known slip, the page says what the slip is.

The walk-throughs end in a full proof, so the proof you bring to class should still be your own, in your own words.

Pólya walk-through · Problem 4.2.1

Close enough, without knowing the answer

Problem 4.2.1. Use the fact that
\[1-\frac12+\frac13-\cdots+\frac{(-1)^{2k+1}}{2k}\le\ln 2\le 1-\frac12+\frac13-\cdots+\frac{(-1)^{2k+2}}{2k+1}\]
to determine how many terms of the series \(\displaystyle\sum_{n=1}^\infty\frac{(-1)^{n+1}}{n}\) should be added together to approximate \(\ln 2\) to within \(.0001\), without actually computing what \(\ln 2\) is.

Goal: Use the trapping inequality to decide how many terms are enough, without ever computing \(\ln 2\). It builds on the reading’s picture of the partial sums closing in from both sides, and it previews Chapter 7, where remainder estimates do this job for Taylor series.

Pólya walk-through · Problem 4.2.3

Same terms, new order

Problem 4.2.3. Show that there is a rearrangement of \(1-\frac12+\frac13-\frac14+\cdots\) which diverges to \(\infty\).

Goal: Reorder the terms so that the partial sums climb past every number you name, and prove that they do. It uses the same two supplies of terms as Riemann’s Theorem 4.2.2, and it sets up 4.2.4, where the supplies run the other way.

Pólya walk-through · Problem 4.2.4

The same supplies, run downward

Problem 4.2.4. Show that there is a rearrangement of \(1-\frac12+\frac13-\frac14+\cdots\) which diverges to \(-\infty\).

Goal: Reorder the terms so that the partial sums fall below every number you name, and prove that they do. It is the mirror image of 4.2.3, with the same two supplies run in the other direction, and it shows that the supplies can drive the sums either way.

Pólya walk-through · Problem 4.3.1

Expand around a, not around 0

Problem 4.3.1. Use Taylor’s formula to find the Taylor series of each function, expanded about the given point \(a\).
(a) \(f(x) = \ln(1+x)\), \(a = 0\)
(b) \(f(x) = e^x\), \(a = -1\)
(c) \(f(x) = x^3 + x^2 + x + 1\), \(a = 0\)
(d) \(f(x) = x^3 + x^2 + x + 1\), \(a = 1\)

Goal: Find the coefficients \(\frac{f^{(n)}(a)}{n!}\) for four expansions, and check one of them by putting in a value. It builds on the Taylor series of Days 12 and 13, and it previews Chapter 7, where you will need to know how many of these terms are enough.
