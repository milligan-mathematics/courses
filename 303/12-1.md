# §12.1: Vector-Valued Functions

So far, every function you have met in this course took numbers (or points) in and handed a number back. A path through space needs something different. If you want to say where a drone is, a roller-coaster car is, or a planet is, you need three coordinates at once, and they all change together as time passes. A **vector-valued function** does exactly that: you feed it one number $$t$$, and it hands back a vector, the position at that moment.

Once a path is a function, the calculus you already know comes along for free. The derivative becomes a velocity vector, the integral recovers a position from an acceleration, and the good news is that almost nothing new has to be learned: you do everything one coordinate at a time.

By the end of this section you should be able to:

1. Evaluate a vector function, find its domain, and describe the space curve it traces.
2. Take limits, derivatives, and integrals of a vector function component by component.
3. Interpret $$\mathbf{r}'(t)$$ as a tangent (velocity) vector, use it to write a tangent line, and say when a curve is smooth.
4. Describe the intersection of two surfaces with a vector function.
5. Recover velocity and position from acceleration and initial conditions.

### A function that outputs a vector

A vector function in space looks like

$$\mathbf{r}(t) = \langle f(t),\, g(t),\, h(t) \rangle = f(t)\,\mathbf{i} + g(t)\,\mathbf{j} + h(t)\,\mathbf{k}.$$

The three scalar functions $$f, g, h$$ are the **component functions**, and $$t$$ is the **parameter**. Read $$\mathbf{r}(t)$$ as a position vector: its tip sits at the point $$(x, y, z) = (f(t), g(t), h(t))$$. As $$t$$ moves through an interval, the tip sweeps out a **space curve**, and the equations $$x = f(t)$$, $$y = g(t)$$, $$z = h(t)$$ are its parametric equations. The domain is wherever all three components are defined.

> **Worked example.** Describe the curve $$\mathbf{r}(t) = \langle \cos t, \sin t, t \rangle$$ for $$-2\pi \le t \le 2\pi$$.
>
> Look at $$x$$ and $$y$$ first: $$x^2 + y^2 = \cos^2 t + \sin^2 t = 1$$, so the point always sits above or below the unit circle in the $$xy$$-plane. Now add $$z = t$$: as $$t$$ increases the point climbs. The curve is a **helix** wrapped around the cylinder $$x^2 + y^2 = 1$$, making two full turns as $$z$$ runs from $$-2\pi$$ to $$2\pi$$. Replace $$z = t$$ by $$z = -t$$ and the same curve is traced downward instead.

### Limits and continuity

The limit of a vector function is the vector of the limits: if each of $$\lim f$$, $$\lim g$$, $$\lim h$$ exists as $$t \to a$$, then

$$\lim_{t \to a} \mathbf{r}(t) = \left\langle \lim_{t \to a} f(t),\ \lim_{t \to a} g(t),\ \lim_{t \to a} h(t) \right\rangle.$$

(The $$\varepsilon$$–$$\delta$$ version replaces $$\lvert x - L \rvert$$ with the length $$\lVert \mathbf{r}(t) - \mathbf{L} \rVert$$.) Continuity works the same way: $$\mathbf{r}$$ is continuous exactly when all three components are.

> **Worked example.** Find $$\displaystyle\lim_{t \to 0} \left\langle 2 - \frac{\sin t}{t},\ -3 + 3t^2,\ \sqrt{4 - t} \right\rangle$$.
>
> First component: $$\lim_{t\to 0} \frac{\sin t}{t} = 1$$, so the limit is $$2 - 1 = 1$$. Second: substitute, $$-3 + 0 = -3$$. Third: $$\sqrt{4}$$ is continuous at $$t = 0$$, giving $$2$$. So the limit is $$\langle 1, -3, 2 \rangle$$.

### Curves from intersecting surfaces

Two surfaces usually meet in a curve. To describe it, choose one variable (or a trig substitution) to be the parameter and solve for the others so that **both** equations hold.

> **Worked example.** Describe the intersection of the cylinder $$x^2 + y^2 = 4$$ and the plane $$x + z = 2$$.
>
> The cylinder asks for a circle of radius $$2$$ in $$x$$ and $$y$$, so let $$x = 2\cos t$$ and $$y = 2\sin t$$. The plane then forces $$z = 2 - x = 2 - 2\cos t$$. Therefore
>
> $$\mathbf{r}(t) = \langle 2\cos t,\ 2\sin t,\ 2 - 2\cos t \rangle, \qquad 0 \le t \le 2\pi.$$
>
> It is an ellipse: a plane that is not parallel to the cylinder's axis slices the cylinder in an ellipse. A quick check: at $$t = \pi$$ the point is $$(-2, 0, 4)$$, which is on the cylinder and on the plane.

### The derivative and the tangent line

The derivative is defined by the same limit as before,

$$\mathbf{r}'(t) = \lim_{\Delta t \to 0} \frac{\mathbf{r}(t + \Delta t) - \mathbf{r}(t)}{\Delta t} = \langle f'(t),\, g'(t),\, h'(t) \rangle.$$

The numerator is the displacement vector between two points on the curve, so the quotient is an average velocity, and the limit is the instantaneous one. Geometrically, $$\mathbf{r}'(t)$$ is the **tangent vector** to the curve at $$\mathbf{r}(t)$$. It points in the direction of increasing $$t$$, and its length $$\lVert \mathbf{r}'(t) \rVert$$ is the **speed**. A curve is **smooth** on an interval when $$\mathbf{r}'$$ is continuous and never the zero vector. Where $$\mathbf{r}'(t) = \mathbf{0}$$ you can get a corner or a cusp.

> **Worked example.** Find $$\mathbf{r}'(t)$$ for $$\mathbf{r}(t) = \langle t^3 - t,\ e^{-t},\ \ln t \rangle$$, $$1 \le t \le 3$$.
>
> Differentiate each component: $$\mathbf{r}'(t) = \left\langle 3t^2 - 1,\ -e^{-t},\ \dfrac{1}{t} \right\rangle$$. This is valid on the whole interval because $$\ln t$$ and $$1/t$$ both need $$t > 0$$.

A tangent line is a line through $$\mathbf{r}(t_0)$$ in the direction $$\mathbf{r}'(t_0)$$: $$\mathbf{L}(s) = \mathbf{r}(t_0) + s\,\mathbf{r}'(t_0)$$.

> **Worked example.** Find the tangent line to the helix $$\mathbf{r}(t) = \langle \cos t, \sin t, t \rangle$$ at the point $$\left(\tfrac{1}{\sqrt{2}}, \tfrac{1}{\sqrt{2}}, \tfrac{\pi}{4}\right)$$.
>
> The $$z$$-coordinate gives $$t_0 = \pi/4$$, and $$\cos\frac{\pi}{4} = \sin\frac{\pi}{4} = \frac{1}{\sqrt{2}}$$ confirms it. Then $$\mathbf{r}'(t) = \langle -\sin t, \cos t, 1 \rangle$$, so $$\mathbf{r}'(\pi/4) = \left\langle -\tfrac{1}{\sqrt{2}}, \tfrac{1}{\sqrt{2}}, 1 \right\rangle$$ and
>
> $$\mathbf{L}(s) = \left\langle \tfrac{1}{\sqrt{2}}, \tfrac{1}{\sqrt{2}}, \tfrac{\pi}{4} \right\rangle + s\left\langle -\tfrac{1}{\sqrt{2}}, \tfrac{1}{\sqrt{2}}, 1 \right\rangle.$$
>
> Try the demo with the helix at $$t \approx 0.785$$ and watch the orange arrow.

The familiar rules carry over, with one caution about order. For differentiable $$\mathbf{u}(t)$$, $$\mathbf{v}(t)$$, a scalar function $$f(t)$$, and a constant vector $$\mathbf{C}$$:

$$\frac{d}{dt}[\mathbf{C}] = \mathbf{0}, \qquad \frac{d}{dt}[f\,\mathbf{u}] = f'\mathbf{u} + f\,\mathbf{u}', \qquad \frac{d}{dt}[\mathbf{u} \pm \mathbf{v}] = \mathbf{u}' \pm \mathbf{v}',$$

$$\frac{d}{dt}[\mathbf{u} \cdot \mathbf{v}] = \mathbf{u}' \cdot \mathbf{v} + \mathbf{u} \cdot \mathbf{v}', \qquad \frac{d}{dt}[\mathbf{u} \times \mathbf{v}] = \mathbf{u}' \times \mathbf{v} + \mathbf{u} \times \mathbf{v}', \qquad \frac{d}{dt}[\mathbf{u}(f(t))] = f'(t)\,\mathbf{u}'(f(t)).$$

The common mistake: in the cross-product rule, keep $$\mathbf{u}$$ first and $$\mathbf{v}$$ second in **both** terms. Cross products change sign when you swap, so writing $$\mathbf{v} \times \mathbf{u}'$$ gives the wrong answer.

### Integrals

Integrate each component. An indefinite integral picks up a constant **vector** $$\mathbf{C} = \langle C_1, C_2, C_3 \rangle$$, and the Fundamental Theorem still holds: $$\int_a^b \mathbf{r}(t)\,dt = \mathbf{R}(b) - \mathbf{R}(a)$$ for any antiderivative $$\mathbf{R}$$. The classic use is going from acceleration back to velocity and then to position, using the starting conditions to fix the constants.

> **Worked example.** A particle has acceleration $$\mathbf{a}(t) = \langle \cos t, 0, -2 \rangle$$, starts at $$\mathbf{r}(0) = \langle 1, 0, 0 \rangle$$, and has initial velocity $$\mathbf{v}(0) = \langle 0, 1, 4 \rangle$$. Find $$\mathbf{v}(t)$$, $$\mathbf{r}(t)$$, and the position at $$t = \pi$$.
>
> Integrate once: $$\mathbf{v}(t) = \langle \sin t + C_1,\ C_2,\ -2t + C_3 \rangle$$. Setting $$t = 0$$ and matching $$\langle 0, 1, 4 \rangle$$ gives $$\mathbf{C} = \langle 0, 1, 4 \rangle$$, so $$\mathbf{v}(t) = \langle \sin t,\ 1,\ 4 - 2t \rangle$$.
>
> Integrate again: $$\mathbf{r}(t) = \langle -\cos t + D_1,\ t + D_2,\ 4t - t^2 + D_3 \rangle$$. Matching $$\mathbf{r}(0) = \langle 1, 0, 0 \rangle$$ gives $$D_1 = 2$$, $$D_2 = D_3 = 0$$, so
>
> $$\mathbf{r}(t) = \langle 2 - \cos t,\ t,\ 4t - t^2 \rangle, \qquad \mathbf{r}(\pi) = \langle 3,\ \pi,\ 4\pi - \pi^2 \rangle.$$
>
> Check: $$\int_0^{\pi} \mathbf{v}\,dt = \langle 2, \pi, 4\pi - \pi^2 \rangle$$, which is exactly $$\mathbf{r}(\pi) - \mathbf{r}(0)$$.

### Practice & reflection

1. The curve $$\mathbf{r}(t) = \langle t^2, t^3, 0 \rangle$$ is a plane curve. What is its velocity vector at $$t = 0$$? Is the curve smooth there? Sketch what it looks like near the origin, then check with the cusp preset in the demo.
2. The difference quotient $$\frac{\mathbf{r}(t + \Delta t) - \mathbf{r}(t)}{\Delta t}$$ is a vector that points along a chord of the helix. Describe what happens to its direction as $$\Delta t \to 0$$.
3. Why does the cross-product rule need its terms in a fixed order, while the dot-product rule does not?
4. If you know only the acceleration $$\mathbf{a}(t)$$ of a particle, can you find its position? What information is missing, and how many constants of integration are there?
