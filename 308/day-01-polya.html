How these work. Each walk-through takes one exercise through Pólya’s four phases. You answer one step at a time and get feedback right away; when something isn’t right, read why and try again. Hints are there when you ask for them. Your place is saved in this browser, so you can stop and come back.

The walk-throughs end in full solutions, so the work you present in class should still be your own, in your own words.

Pólya walk-through · Exercise 1.4.1

Describing sets built from A, B and C

Exercise 1.4.1. Suppose that \(A = \{x : x \in \mathbb N \text{ and } x \text{ is even}\}\), \(B = \{x : x \in \mathbb N \text{ and } x \text{ is prime}\}\), and \(C = \{x : x \in \mathbb N \text{ and } x \text{ is a multiple of } 5\}\). Describe each of the following sets.
(a) \(A \cap B\)
(b) \(B \cap C\)
(c) \(A \cup B\)
(d) \(A \cap (B \cup C)\)

Goal: Describe a set by the rule its members follow, and make sure the description covers every number, not just the first few. It uses the set operations and \(\mathbb N\) from Section 1.2, and the distributive law in Proposition 1.2.2, which the Look back step uses. Nothing beyond the reading is needed.

Pólya walk-through · Exercise 1.4.17

A rule that names a number two ways

Exercise 1.4.17. Which of the following relations \(f : \mathbb Q \to \mathbb Q\) define a mapping? In each case, supply a reason why \(f\) is or is not a mapping.
(a) \(f(p/q) = \frac{p + 1}{p - 2}\)
(b) \(f(p/q) = \frac{3p}{3q}\)
(c) \(f(p/q) = \frac{p + q}{q^2}\)
(d) \(f(p/q) = \frac{3p^2}{7q^2} - \frac{p}{q}\)

Goal: Decide whether a rule gives exactly one output for each rational number, even when a rational number has many names as \(p/q\). It uses the definition of a mapping and of well-defined from Section 1.2, and the lowest-terms convention in Example 1.2.8.

Pólya walk-through · Exercise 1.4.20

One-to-one and onto, separately

Exercise 1.4.20. (a) Define a function \(f : \mathbb N \to \mathbb N\) that is one-to-one but not onto.
(b) Define a function \(f : \mathbb N \to \mathbb N\) that is onto but not one-to-one.

Goal: Build a map that has one of the two properties and not the other, and prove which property holds. It uses the definitions of one-to-one and onto from Section 1.2. Keeping the two properties apart is what makes the bijections of later sections mean something.
