How these work. Each walk-through takes one problem through Pólya’s four phases. You answer one step at a time and get feedback right away; when something isn’t right, read why and try again. Hints are there when you ask for them. Your place is saved in this browser, so you can stop and come back.

Each problem builds on the ones before it, starting from Property 1, \(E(0)=1\), and Property 2, \(E(x+y)=E(x)E(y)\). Nothing here needs limits. When a step multiplies two power series, do it term by term, as the reading does for Property 2. The one place derivatives come up is a look-back question in 3.2.4, and there the term-by-term derivative is a formal step, not a claim about convergence.

The walk-throughs end in a full proof, so the proof you bring to class should still be your own, in your own words.

Pólya walk-through · Problem 3.2.3

Split \(mx\) into copies of \(x\)

Problem 3.2.3. Recall that \(E(x) = \sum_{n=0}^\infty \frac{x^n}{n!}\), and that Properties 1 and 2 hold: \(E(0) = 1\) and \(E(x+y) = E(x)E(y)\).
Prove Property 3: if \(m\) is a positive whole number, then \(E(mx) = \bigl(E(x)\bigr)^m\).

Goal: Prove a statement about every positive whole number \(m\) at once. Start with the case \(m = 1\), then find how to get from \(m - 1\) to \(m\), using Property 2. It uses Property 2, the functional equation the series for \(E\) satisfies. Properties 4 to 6 come from the same equation, and the next three problems prove them.

Pólya walk-through · Problem 3.2.4

Negate the input, invert the output

Problem 3.2.4. Recall Properties 1 and 2: \(E(0) = 1\) and \(E(x+y) = E(x)E(y)\).
Prove Property 4: \(E(-x) = \dfrac{1}{E(x)} = \bigl(E(x)\bigr)^{-1}\) for every real number \(x\).

Goal: Get \(E(-x)\) from \(E(0) = 1\) and Property 2, and explain why dividing by \(E(x)\) is allowed. It uses only Properties 1 and 2, and it gives the negative case that Problems 3.2.5 and 3.2.6 need.

Pólya walk-through · Problem 3.2.5

The \(n\)th root of \(E(1)\)

Problem 3.2.5. Recall Properties 1 to 4: \(E(0) = 1\), \(E(x+y) = E(x)E(y)\), \(E(mx) = \bigl(E(x)\bigr)^m\) for positive whole \(m\), and \(E(-x) = \frac{1}{E(x)}\).
Prove Property 5: if \(n\) is an integer with \(n \ne 0\), then \(E\bigl(\tfrac1n\bigr) = \sqrt[n]{E(1)} = \bigl(E(1)\bigr)^{1/n}\).

Goal: Pin down \(E\bigl(\tfrac1n\bigr)\) in terms of \(E(1)\) for every nonzero integer \(n\), positive or negative. It uses Properties 2 to 4, and it gives \(E\) at unit fractions. Problem 3.2.6 combines these into every rational exponent.

Pólya walk-through · Problem 3.2.6

Every rational exponent, \(\frac mn\)

Problem 3.2.6. Recall Properties 1 to 5, including Property 5: \(E\bigl(\tfrac1n\bigr) = \bigl(E(1)\bigr)^{1/n}\) for every nonzero integer \(n\).
Prove Property 6: if \(m\) and \(n\) are integers with \(n \ne 0\), then \(E\bigl(\tfrac mn\bigr) = \bigl(E(1)\bigr)^{m/n}\).

Goal: Cover every fraction \(\frac mn\), with \(m\) of either sign and \(n\) any nonzero integer, by combining Properties 3, 4 and 5. It finishes the rational case: Properties 3 to 5 each covered part of it, and this one covers all of it.
