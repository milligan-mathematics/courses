How these work. Each walk-through takes one problem through Pólya’s four phases. You answer one step at a time and get feedback right away; when something isn’t right, read why and try again. Hints are there when you ask for them. Your place is saved in this browser, so you can stop and come back.

Something new: you name a term that escapes. Some steps ask you to type a formula. The page plays the adversary from Definition 6.1.11: it names a number \(N\), and you type an \(n > N\) whose term lands outside the band of radius \(\varepsilon\) around the limit you are testing. Any formula that works is right, not only the one in the model proof. The page tests it against many challenges, from small \(N\) to very large ones, so passing is strong evidence but not a proof. If yours fails, you’ll see the exact \(N\) that beat it.

The walk-throughs end in full proofs, so the proof you bring to class should still be your own, in your own words.

Pólya walk-through · Problem 6.3.4

Climb past any height

Problem 6.3.4. Show that the sequence \((n)_{n=1}^\infty\) diverges to infinity.

Goal: Use Definition 6.3.3 itself, not the weaker idea of divergence: for each height \(r\), find an \(N\) that works for every \(n\) past it. It applies the definition of divergence to infinity from the reading. Problem 6.3.5 then shows that a sequence diverging to infinity also diverges, so this is the first of the divergence results in this set.

Pólya walk-through · Problem 6.3.5

A sequence cannot do both

Problem 6.3.5. Show that if \((a_n)_{n=1}^\infty\) diverges to infinity, then \((a_n)_{n=1}^\infty\) diverges.

Goal: Show that no real number can be a limit of \((a_n)\), using the definition of convergence and the definition of divergence to infinity together. It is the first result that connects the two definitions in Section 6.3. It also shows that the notation \(\lim a_n = \infty\) names a kind of divergence, not a limit. Problem 6.3.10 uses it.

Pólya walk-through · Problem 6.3.6

Sums, products, quotients

Problem 6.3.6. Suppose \(\lim_{n\to\infty} a_n = \infty\) and \(\lim_{n\to\infty} b_n = \infty\). Show that \(\lim_{n\to\infty}(a_n + b_n) = \infty\), and that \(\lim_{n\to\infty} a_n b_n = \infty\). Is it true that \(\lim_{n\to\infty} \frac{a_n}{b_n} = \infty\)? Explain.

Goal: Check which limit rules survive when the limits are infinite, and prove each one that survives from Definition 6.3.3. It builds on Problem 6.3.5 and on the sum, product and quotient theorems of Section 6.2. Those theorems need real limits, so each claim here has to be argued from the definition. Problem 6.3.7 tests the same rules with one sequence going to \(-\infty\).

Pólya walk-through · Problem 6.3.7

Which rules survive a minus sign

Problem 6.3.7. Suppose \(\lim_{n\to\infty} a_n = \infty\), \(\lim_{n\to\infty} b_n = -\infty\), and \(\alpha \in \mathbb{R}\). Prove or give a counterexample: (1) \(\lim_{n\to\infty}(a_n + b_n) = \infty\); (2) \(\lim_{n\to\infty} a_n b_n = -\infty\); (3) \(\lim_{n\to\infty} \alpha a_n = \infty\); (4) \(\lim_{n\to\infty} \alpha b_n = -\infty\).

Goal: Decide each of the four claims: prove the true one from Definition 6.3.3, and give counterexamples for the others. It continues Problem 6.3.6 with one sequence going to \(-\infty\). The sign of the limit now matters, and the claims about scalars need \(\alpha\) checked at \(0\) and at negative values.

Pólya walk-through · Problem 6.3.8

Three ways to have no limit

Problem 6.3.8. Show that each of the following sequences diverges: (1) \(\left((-1)^n\right)_{n=1}^\infty\); (2) \(\left((-1)^n n\right)_{n=1}^\infty\); (3) \(a_n = 1\) if \(n = 2^p\) for some \(p \in \mathbb{N}\), and \(a_n = \frac1n\) otherwise.

Goal: Show that each sequence has no real limit: for every \(L\), find a bad \(\varepsilon\), and then a term past any \(N\) that lands at least \(\varepsilon\) from \(L\). It applies the negation of Definition 6.1.11 (convergence to a real number) to three sequences. Part (3) needs an argument from the definition alone, because the course has not yet reached subsequences.

Pólya walk-through · Problem 6.3.9

Scaling a sequence that won’t settle

Problem 6.3.9. Suppose that \((a_n)_{n=1}^\infty\) diverges but not to infinity, and that \(\alpha\) is a real number. What conditions on \(\alpha\) will guarantee that \((\alpha a_n)_{n=1}^\infty\) converges? That it diverges?

Goal: Decide for which \(\alpha\) the scaled sequence must converge, and for which it must diverge, using the definitions and a division by \(\alpha\). It uses Corollary 6.2.10 to divide back by \(\alpha\), and the definition of divergence (Definition 6.3.1). Problem 6.3.10 looks at the powers \(r^n\), which form a geometric sequence.

Pólya walk-through · Problem 6.3.10

Powers that won’t settle

Problem 6.3.10. Show that if \(|r| > 1\), then \((r^n)_{n=1}^\infty\) diverges. Will it diverge to infinity?

Goal: Split into the cases \(r > 1\) and \(r < -1\). In the first, find a bound that grows without limit. In the second, handle the sign flips and write the argument out. It uses Problem 6.3.5 (divergence to infinity implies divergence) and Lemma 6.2.7 (convergent sequences are bounded). The powers \(r^n\) are the terms of the geometric series, which you met with the power series in Days 7 to 11.
