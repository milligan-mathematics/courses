Walk-through · Part A

One neuron

Part A. Do Part A on paper first, then check in here.
A neuron takes inputs \(\mathbf x\), computes a linear model \(z = \mathbf w\cdot\mathbf x + b\) (exactly Day 11’s), and then applies an activation function \(a = g(z)\). The two you need: \(\operatorname{ReLU}(z) = \max\{0, z\}\) (“rectified linear unit”) and \(\sigma(z) = \dfrac{1}{1 + e^{-z}}\) (“sigmoid”).
1. Fill in a table of \(\operatorname{ReLU}(z)\) and \(\sigma(z)\) for \(z = -4, -2, -1, 0, 1, 2, 4\) (a calculator is fine for \(e^{-z}\); two decimals). Sketch both on the Part A axes.
2. A neuron with a sigmoid outputs a number between 0 and 1, which we read as “how sure it is the label is \(+1\).” Explain why \(\sigma(\mathbf w\cdot\mathbf x + b) \ge 0.5\) exactly when \(\mathbf w\cdot\mathbf x + b \ge 0\). So which earlier classifier is a single sigmoid neuron, if you say “\(+1\)” whenever the output is at least 0.5?
3. One input, \(h = \operatorname{ReLU}(x - 2)\) (so \(w = 1\), \(b = -2\)). Where is the bend? What is the slope on each side? Now \(h = \operatorname{ReLU}(3 - x)\): bend, slopes, and which side is flat?

Goal: Compute the two activations by hand, see that a sigmoid neuron is a linear classifier in disguise, and read a ReLU’s bend and slopes straight off its formula. Part B adds several bent ReLUs together to make a bent line of any shape; Part D differentiates the sigmoid, which is how a network learns.

Walk-through · Part B

Adding bends

Part B. Do Part B on paper first, then check in here.
One hidden layer. A network with one hidden layer feeds the input into several neurons (the hidden layer) and adds their outputs with new weights: \(\hat y = v_1h_1 + v_2h_2 + \cdots + c\).
1. Take two hidden neurons, \(h_1 = \operatorname{ReLU}(x)\) and \(h_2 = \operatorname{ReLU}(x - 2)\), and the output \(\hat y = h_1 - 2h_2 + 1\). Make a table of \(h_1\), \(h_2\), and \(\hat y\) for \(x = -1, 0, 1, 2, 3, 4, 5\), and sketch \(\hat y\) on the Part B axes.
2. Your graph should be a bent line. Where are the bends? What is the slope of each straight piece? Explain how the output weights \(v_1 = 1\) and \(v_2 = -2\) show up as changes in slope at the bends.
3. Design one. Build a function that equals 4 for \(x \le 1\), then falls with slope \(-2\) until \(x = 2\), then keeps falling but with slope only \(-0.5\). (That’s the shape of mpg against horsepower: steep at first, then flattening. On Day 17 a horsepower\(^2\) term did this job.) Use \(\hat y = c + v_1\operatorname{ReLU}(x - 1) + v_2\operatorname{ReLU}(x - 2)\) and find \(c\), \(v_1\), \(v_2\). Check at \(x = 0\), \(2\), and \(4\).
4. A curve with five bends needs how many ReLU neurons? Explain why a network with enough hidden neurons can follow almost any curve you draw (as a bent line with many short pieces).
Skeptic. “The bend is just decoration. Leave out the activation and stack two layers of plain linear models; two layers must be more powerful than one.” Write \(\hat y = v_1(w_1x + b_1) + v_2(w_2x + b_2) + c\) and simplify. What kind of function is it? (With matrices: \(W_2(W_1\mathbf x + \mathbf b_1) + \mathbf b_2 = (W_2W_1)\mathbf x + \cdots\).)

Goal: Build bent lines by adding ReLUs, read each output weight as a change of slope, design one to order, and see why the bend is the whole point. Part A gave one bend; here bends add up. Part C does the same thing in two dimensions, with lines in the plane in place of bends on a line.

Walk-through · Part C

Bending a boundary

Part C. Do Part C on paper first, then check in here.
Back to Day 34’s two rings, now with a network instead of a kernel. Use the step activation, \(\operatorname{step}(z) = 1\) if \(z \ge 0\) and \(0\) otherwise (a sigmoid with very large weights looks just like it). Four hidden neurons with two inputs \((x_1, x_2)\): \(h_1 = \operatorname{step}(1 - x_1)\), \(h_2 = \operatorname{step}(1 + x_1)\), \(h_3 = \operatorname{step}(1 - x_2)\), \(h_4 = \operatorname{step}(1 + x_2)\), and one output neuron, \(\text{out} = \operatorname{step}(h_1 + h_2 + h_3 + h_4 - 3.5)\), with “\(+1\)” when out \(= 1\). The figure’s points: inner \(Q_1(0.5, 0)\), \(Q_2(0, 0.6)\), \(Q_3(-0.4, -0.3)\), \(Q_4(0.3, -0.4)\); outer \(R_1(2, 0)\), \(R_2(0, -2)\), \(R_3(-1.6, 1.2)\), \(R_4(1.2, 1.6)\).
1. Each hidden neuron is a Day 31 line: \(h_1 = 1\) on one side of the line \(x_1 = 1\). Draw all four lines on the figure and mark which side of each has \(h = 1\).
2. For which points is \(h_1 + h_2 + h_3 + h_4 = 4\)? What region of the plane gets out \(= 1\)? Check all eight ring points: does the network label them correctly?
3. Is the boundary straight? How many weights and biases does this network have in all? How would you make the boundary rounder?
4. What does the output neuron do with its four inputs, in one word? (Think about why the threshold is 3.5 and not, say, 0.5.)

Goal: Build a closed boundary out of four straight lines, label the rings with it, and see the output neuron acting as a logic gate. Part B made a bent line from bends; here a bent boundary comes from lines. Day 34 needed a kernel to curve the boundary; the network makes its own corners. On Wednesday it finds the lines itself.

Walk-through · Part D

How a network learns: the chain rule

Part D. Do Part D on paper first, then check in here.
Nobody picks the weights by hand for real data. As on Day 13, we choose a loss and run gradient descent. The only new problem is computing the gradient through the layers, and the tool is the chain rule from calculus. Take a single sigmoid neuron with one input, \(z = wx + b\), \(\hat y = \sigma(z)\), \(L = (\hat y - y)^2\), and one training point \(x = 1\), \(y = 1\), starting from \(w = 0\), \(b = 0\).
1. Compute \(z\), \(\hat y\), and \(L\).
2. The chain rule: \(\dfrac{\partial L}{\partial w} = \dfrac{\partial L}{\partial \hat y}\cdot\dfrac{\partial \hat y}{\partial z}\cdot\dfrac{\partial z}{\partial w}\). Use \(\dfrac{\partial L}{\partial \hat y} = 2(\hat y - y)\), the handy fact \(\sigma^{\prime}(z) = \sigma(z)\big(1 - \sigma(z)\big)\), and \(\dfrac{\partial z}{\partial w} = x\). Compute each factor and the product.
3. Take one gradient-descent step with learning rate 1: \(w_{\text{new}} = w - 1\cdot\dfrac{\partial L}{\partial w}\). Recompute \(\hat y\) and \(L\) with the new \(w\) (keep \(b = 0\)). Did the loss go down?

Goal: Push one training point forward through a neuron, push the error back with the chain rule, and watch one step of gradient descent lower the loss. This is Day 13’s gradient descent with one new ingredient, the chain rule through the activation. On Wednesday the same three factors, one set per layer, become a few lines of code: backpropagation.
