The Great Algebra Escape: Mission Impossible?

Companion to Bailey's handout — your written work still goes on the paper.

Mission Brief:

We are trapped inside the Algebra Lab! Four locks stand between us and freedom. Work through each clue in order. Your goal is not only to find an answer, but to explain WHY your answer works. Start with Lock 1. Read the clue card carefully. Solve or analyze the equation. Explain your reasoning. When the class agrees, move to the next lock. The final lock requires you to create and test your own equations.

Every move you make in the lab below gets applied to both sides. That is the only rule the lab enforces — it will never tell you which move to make.

Clue I: Find The Code

The first door needs a number. Clue: 7x − 15 = 3x + 9

Lock 1 Code: ▮ the value of x
Clue II: FALSE ALARM

The computer claims there is a value of x that will open the next door. Clue: 2(3x + 5) + 4x = 10x + 18

Step 1: Is the statement true or false?

Step 2: Is there ANY value of x that can make the original equation true?

Step 3: Classify the equation.

Lock 2 Code: ▮ how many solutions this equation has
Clue III: The Infinite Loop

The computer is stuck in a loop. It says the equation is always true. Clue: 3(2x + 4) − 2x = 4x + 12

Step 2: Is that statement true or false?

Step 3: What does this tell you about the number of solutions?

Try it yourself: pick any number for x and watch both sides.

Lock 3 Code: ▮ the infinity symbol, tipped over
Clue IV: The Master Lock

HOME STRETCH —> We made it to the final door! This time, the computer does NOT give us the equations. You MUST design them (Make them challenging!).

Type a whole equation, including the equals sign. The lock will simplify both sides and report what it finds — it checks your equation, it does not write it for you.

Swap with a partner. Have them classify all three of your equations and explain their reasoning.

Teacher notes & answer key

Bailey's handout is the record of student work; this page is the shared screen. Everything below matches the PDF, in the same order.

Lock Equation What happens Code
1 7x − 15 = 3x + 9 4x = 24, so x = 6. One solution. 6
2 2(3x + 5) + 4x = 10x + 18 10x + 10 = 10x + 18, so 10 = 18. False — no solution. 0
3 3(2x + 4) − 2x = 4x + 12 4x + 12 = 4x + 12, so 12 = 12. True — infinitely many. 8
4 student-designed One solution, no solution, all values — each verified by the checker. 3

Final code: 6083. The codes follow a rule students can state out loud: Lock 1 is the value of x, Lock 2 is the number of solutions, Lock 3 is the infinity symbol tipped on its side, and Lock 4 is the 3 the handout asks for. To change any code, edit the CODES object at the top of the script in this file.

Where the page helps and where it stays quiet. The balance lab applies whatever move a student names to both sides and simplifies — it never suggests a move, so the choice of what to undo first is still theirs. Locks 2 and 3 will not confirm a classification until the true/false question underneath it is also right, so a lucky guess on the classification does not open the lock.

Lock 4 is the one to project. The checker accepts any linear equation, so 2x + 1 = 2x + 7 and 5(x − 3) = 5x − 15 both get read the same way the class reads them. Good discussion equations to try together if the room stalls: x + 1 = x + 1 (all values), then x + 1 = x + 2 (none) — one symbol apart.

Student work is saved in this browser only. Typed answers persist through a reload on the same device; "Clear my work" wipes them. Nothing is submitted anywhere, so the handout is still what gets turned in.
