How these work. Each walk-through takes one problem through Pólya’s four phases. You answer one step at a time and get feedback right away; when something isn’t right, read why and try again. Hints are there when you ask for them. Your place is saved in this browser, so you can stop and come back.

Something new: you name \(\delta\). Definition 8.1.7 is the Day 17 game with new pieces: the opponent names \(\varepsilon\), and you answer with a \(\delta\). Some steps ask you to type \(\delta\) as a formula in \(\varepsilon\) (type eps). The page then plays the opponent: it names challenges from \(\varepsilon = 10\) down to \(\varepsilon = 0.000001\), and for each one it hunts for an \(x\) within your \(\delta\) of \(a\) whose value \(f(x)\) lands outside the band around \(f(a)\). Any \(\delta\) that survives is right, not only the one in the model proof. The page samples many points, so passing is strong evidence, not a proof. If yours fails, you’ll see the challenge and the \(x\) that beat it.

Problem 8.1.5 asks for a computer algebra system. These walk-throughs don’t draw the plots; they walk through what to compute, what the plots show, and why.

The walk-throughs end in full proofs, so the proof you bring to class should still be your own, in your own words.

Pólya walk-through · Problem 8.1.5

A curve with no smooth spot

Problem 8.1.5. (a) Given \(f(x)=\sum_{n=0}^\infty\left(\frac{1}{2}\right)^n\cos\left(a^n\pi x\right)\), what is the smallest value of \(a\) for which \(f\) satisfies Weierstrass’ criterion to be continuous and nowhere differentiable? (b) Let \(f(x,N)=\sum_{n=0}^N\left(\frac{1}{2}\right)^n\cos\left(13^n\pi x\right)\) and use a computer algebra system to plot \(f(x,N)\) for \(N=0,1,2,3,4,10\) and \(x\in[0,1]\). (c) Plot \(f(x,10)\) for \(x\in[0,c]\), where \(c=0.1,0.01,0.001,0.0001,0.00001\). Based upon what you see in parts b and c, why would we describe the function to be somewhat “fractal” in nature?

Goal: Read Weierstrass’s criterion carefully enough to find \(a\), then predict and explain what the plots show: bumps that shrink while their slopes grow, at every scale. This is the function from the reading that broke the guess “continuous means differentiable somewhere”. Problem 8.1.9 starts the other side of the story: proving continuity from Definition 8.1.7.

Pólya walk-through · Problem 8.1.9

Your first \(\delta\)

Problem 8.1.9. Use the definition of continuity to show that if \(m\) and \(b\) are fixed (but unspecified) real numbers then the function \(f(x) = mx+b\) is continuous at every real number \(a\).

Goal: Prove continuity from Definition 8.1.7: for every \(\varepsilon > 0\), name a \(\delta > 0\) that keeps \(f(x)\) within \(\varepsilon\) of \(f(a)\) whenever \(x\) is within \(\delta\) of \(a\), for every line at once. Example 8.1.8 is the case \(m = 1\), \(b = 0\). Day 23 runs the same plan on \(\sqrt{x}\) and \(\sin x\), where finding \(\delta\) takes more work.
