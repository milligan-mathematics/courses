The Locker Problem

Ch. 8 — send the students down the hall, watch the doors, and pick one locker apart until you can say why.

The problem

A school has 1,000 lockers, numbered 1 through 1,000, and all of them start closed. Then 1,000 students walk down the hall in order:

  • Student 1 opens every locker.
  • Student 2 changes every 2nd locker — closing the ones that are open, opening the ones that are closed.
  • Student 3 changes every 3rd locker.
  • … and so on, through Student 1,000, who changes only locker 1,000.

After all 1,000 students have gone by, which lockers are open?

3. Count the factors without listing them

Chapter 8 gives you a second route to the same answer. Break the locker number into primes, and the number of factors falls out of the exponents.

36 = 22 · 32

Any factor of 2a·3b·… is built by choosing an exponent for each prime, so the choices multiply.

4. Now convince us

The pattern is easy to spot and genuinely hard to justify. That gap is the whole point of the activity, so write your conjecture down before you open anything below.

  1. Say it in one sentence. Which lockers are open, and how would you describe them to someone who never saw the simulation?
  2. Say why it has to keep working. Not just for the lockers you tested — all the way to 1,000. Use the words factor and factor pair.
  3. Say it a second way. Now argue it from a prime factorization instead of from a list of factors.
My conjecture is written down. Show me which lockers are open.

Why does an odd number of factors force a perfect square?

Student k touches locker n exactly when k divides n, so locker n gets toggled once per factor of n. It starts closed, so it ends open exactly when n has an odd number of factors.

Factors come in pairs: if a divides n, so does n ÷ a, and the two multiply to n. Listing the factors as pairs (1, n), (2, n/2), … accounts for all of them two at a time — so the count is even, unless some factor is its own partner: a = n ÷ a, that is, a2 = n. That happens exactly when n is a perfect square, and then the middle factor is counted once instead of twice, making the total odd.

Check it on 36: 1×36, 2×18, 3×12, 4×9, 6×6 — four pairs plus the unpaired 6, giving 9 factors.

The same argument from prime factorizations

If n = p1a1 · p2a2 ⋯ pkak, then n has (a1+1)(a2+1)⋯(ak+1) factors.

A product of whole numbers is odd only when every factor in it is odd — so every ai + 1 must be odd, so every ai must be even. And n has all even exponents exactly when n is a perfect square, since then n = (p1a1/2 ⋯ pkak/2)2.

That is the same “even number of each prime” structure we used to show √2 is irrational. The locker problem and the irrationality of √2 are the same observation wearing different clothes.

What if the school had 1,000,000 lockers and 1,000,000 students?

The perfect squares up to 1,000,000 are 12 through 10002, so 1,000 lockers would be open. In general, for N lockers the answer is ⌊√N⌋.

Try it: set the simulation to 500 lockers and predict the count before you run it.

Change the rule: only prime-numbered students touch anything

Set Rule to Only prime-numbered students and run it again. Now which lockers are open?

Locker n is now toggled once per distinct prime factor of n, so it ends open when n has an odd number of distinct primes — 2, 4, 8 (one prime) and 30 = 2·3·5 (three primes) are open, while 6, 12, and 100 (two primes) are closed. Locker 1 has no prime factors at all, so nobody ever touches it and it stays closed.
