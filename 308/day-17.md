  <h2>Fingerprints</h2>

  <p>Isomorphisms rename elements and keep the structure. So each group has a fingerprint that an isomorphism must
    preserve: its order, whether it is abelian and whether it is cyclic, how many elements have each order, and how
    many solutions \(x\) of \(x^2 = e\) there are. If two groups differ in any row, they are not isomorphic. If they
    agree in every row, you still owe a bijection.</p>

  <p>Pick two groups. Before you look, predict which rows will differ. Try \(\mathbb{Z}_2 \times \mathbb{Z}_6\) against
    \(\mathbb{Z}_3 \times \mathbb{Z}_4\) first.</p>

  <h2>Which feature survives a renaming?</h2>

  <div class="mc" data-answer="a">
    <p class="mc-q">Which of these is preserved by every isomorphism?</p>
    <button class="mc-opt" data-key="a">How many elements of order \(2\) the group has.</button>
    <button class="mc-opt" data-key="b">The name of the identity element, such as \(0\) or \(1\).</button>
    <button class="mc-opt" data-key="c">Which element sits in the second row of the table.</button>
    <button class="mc-opt" data-key="d">The subgroup generated by the element named \(1\).</button>
    <div class="mc-fb" data-key="a"><p>Right. An isomorphism is a bijection that respects products, so it carries elements of order \(2\) to elements of order \(2\),
      and the counts agree.</p></div>
    <div class="mc-fb" data-key="b"><p>Names are exactly what an isomorphism changes. \(\mathbb{Z}_4\) calls the identity \(0\), and \(U(10)\) calls it \(1\).
      Both are the identity in their own group.</p></div>
    <div class="mc-fb" data-key="c"><p>Row and column positions depend on how you list the elements, so they are labels, not structure.</p></div>
    <div class="mc-fb" data-key="d"><p>Which element is named \(1\) changes from group to group, so the subgroup it generates can change too.
      Structure is the thing to track.</p></div>
  </div>

  <div class="mc" data-answer="c">
    <p class="mc-q">Which pair of groups is NOT isomorphic?</p>
    <button class="mc-opt" data-key="a">\(\mathbb{Z}_2 \times \mathbb{Z}_3\) and \(\mathbb{Z}_6\), which both have six elements.</button>
    <button class="mc-opt" data-key="b">\(U(8)\) and \(\mathbb{Z}_2 \times \mathbb{Z}_2\), which both have four elements.</button>
    <button class="mc-opt" data-key="c">\(D_5\) and \(\mathbb{Z}_{10}\), which both have ten elements.</button>
    <button class="mc-opt" data-key="d">\(\mathbb{Z}_{10}\) and \(\mathbb{Z}_2 \times \mathbb{Z}_5\), which both have ten elements.</button>
    <div class="mc-fb" data-key="a"><p>These are isomorphic. \(\gcd(2,3) = 1\), so \(\mathbb{Z}_2 \times \mathbb{Z}_3\) is cyclic of order \(6\).</p></div>
    <div class="mc-fb" data-key="b"><p>These are isomorphic. The reading shows \(U(8)\) is isomorphic to \(\mathbb{Z}_2 \times \mathbb{Z}_2\).</p></div>
    <div class="mc-fb" data-key="c"><p>Right. Both have ten elements, but \(\mathbb{Z}_{10}\) is abelian and \(D_5\) is not. Abelian-ness is preserved by
      isomorphisms, so no isomorphism exists.</p></div>
    <div class="mc-fb" data-key="d"><p>These are isomorphic, since \(\gcd(2,5) = 1\) and so \(\mathbb{Z}_2 \times \mathbb{Z}_5\) is cyclic of order \(10\).</p></div>

  <h2>What is an automorphism, really?</h2>

  <div class="mc" data-answer="c">
    <p class="mc-q">Which map from \(\mathbb{Z}_8\) to itself is an automorphism?</p>
    <button class="mc-opt" data-key="a">\(x \mapsto x + 1\)</button>
    <button class="mc-opt" data-key="b">\(x \mapsto 2x\)</button>
    <button class="mc-opt" data-key="c">\(x \mapsto 3x\)</button>
    <button class="mc-opt" data-key="d">Swap \(1\) and \(3\), and fix every other element.</button>
    <div class="mc-fb" data-key="a"><p>Not a homomorphism: it sends the identity \(0\) to \(1\), but a homomorphism must send \(0\) to \(0\).</p></div>
    <div class="mc-fb" data-key="b"><p>It respects addition, since \(2(x + y) = 2x + 2y\), but it is not one-to-one: \(2 \cdot 0 = 2 \cdot 4 = 0\) in \(\mathbb{Z}_8\).</p></div>
    <div class="mc-fb" data-key="c"><p>Right. \(3\) is a unit mod \(8\), so \(x \mapsto 3x\) is one-to-one and onto, and \(3(x + y) = 3x + 3y\).</p></div>
    <div class="mc-fb" data-key="d"><p>It is a bijection that fixes \(0\), but it breaks addition: \(1 + 1 = 2\) goes to \(2\), while the images of \(1\) add to \(3 + 3 = 6\).</p></div>
  </div>

  <h2>Isomorphisms preserve being abelian</h2>

  <p>The reading proves that if \(G\) is abelian, then so is \(H\), whenever \(\varphi\colon G \to H\) is an
    isomorphism. Commit to each step first.</p>

  <div class="proof-scaffold">
    <ol class="scaffold-steps">
      <li class="sstep">
        <div class="sstep-prompt">What must be shown, to conclude \(H\) is abelian?</div>
        <div class="sstep-body"><p>That \(h_1 h_2 = h_2 h_1\) for all \(h_1, h_2 \in H\).</p></div>
      </li>
      <li class="sstep">
        <div class="sstep-prompt">Why can you write \(h_1 = \varphi(g_1)\) and \(h_2 = \varphi(g_2)\) for some \(g_1, g_2 \in G\)?</div>
        <div class="sstep-body"><p>Because \(\varphi\) is onto.</p></div>
      </li>
      <li class="sstep">
        <div class="sstep-prompt">Use the fact that \(\varphi\) respects products to rewrite \(h_1 h_2\) as an image.</div>
        <div class="sstep-body"><p>\(h_1 h_2 = \varphi(g_1)\varphi(g_2) = \varphi(g_1 g_2)\).</p></div>
      </li>
      <li class="sstep">
        <div class="sstep-prompt">Finish the argument. Which hypothesis do you use, and where?</div>
        <div class="sstep-body"><p>\(G\) is abelian, so \(g_1 g_2 = g_2 g_1\). Then \(\varphi(g_1 g_2) = \varphi(g_2 g_1) = \varphi(g_2)\varphi(g_1) = h_2 h_1\).
          The hypothesis is used once, in the middle.</p></div>
      </li>
    </ol>

<div class="act flaw">
  <div class="act-type">Spot the Flaw</div>
  <h2>Is inversion an automorphism?</h2>

  <p>A classmate claims that \(\varphi(x) = x^{-1}\) is an automorphism of every group. Here's the argument.</p>

  <p><strong>Click the step that isn't justified.</strong></p>

  <div class="flaw-widget" data-flaw="3">
    <div class="flawlist">
      <button class="fline" type="button">\(\varphi\) is its own inverse function, since \((x^{-1})^{-1} = x\). So \(\varphi\) is a bijection of \(G\) onto itself.</button>
      <button class="fline" type="button">\(\varphi(e) = e\), since \(e^{-1} = e\).</button>
      <button class="fline" type="button">For all \(x, y\), \(\varphi(xy) = (xy)^{-1} = x^{-1}y^{-1} = \varphi(x)\varphi(y)\).</button>
      <button class="fline" type="button">So \(\varphi\) respects products, and \(\varphi\) is an automorphism of \(G\). \(\blacksquare\)</button>
    </div>
    <div class="flaw-verdict" data-key="1"><p><strong>Fine.</strong> A function that is its own inverse is a bijection.</p></div>
    <div class="flaw-verdict" data-key="2"><p><strong>Fine.</strong> The identity is its own inverse.</p></div>
    <div class="flaw-verdict" data-key="3"><p><strong>This is the flaw.</strong> The inverse of a product reverses the order:
      \((xy)^{-1} = y^{-1}x^{-1}\), the socks-and-shoes rule from Day 3. Here \(x^{-1}y^{-1} \neq y^{-1}x^{-1}\) in general. In \(D_5\), take
      \(x = r\) and \(y = s\). Then \((rs)^{-1} = rs\), because a reflection is its own inverse, but \(r^{-1}s^{-1} = r^{-1}s \neq rs\),
      since \(r \neq r^{-1}\).</p></div>
    <div class="flaw-verdict" data-key="4"><p><strong>Fine, given line 3.</strong> The conclusion follows from the lines before it, so the
      trouble is upstream. The inversion map is an automorphism exactly when the group is abelian.</p></div>
  </div>
</div>

  (function () {
    var A = A308;

    /* ---- Explore 1: fingerprints ---- */
    var groups = [
      ['Z4', A.Z(4)], ['V4', A.V4()], ['Z6', A.Z(6)], ['Z2×Z3', A.product(A.Z(2), A.Z(3))],
      ['Z10', A.Z(10)], ['D5', A.D(5)], ['Z2×Z6', A.product(A.Z(2), A.Z(6))], ['Z3×Z4', A.product(A.Z(3), A.Z(4))]
    ];
    var selL = document.getElementById('d17-L'), selR = document.getElementById('d17-R');
    groups.forEach(function (p, i) {
      selL.appendChild(A.h('option', { value: i, text: p[0] }));
      selR.appendChild(A.h('option', { value: i, text: p[0] }));
    });
    selL.value = 6; selR.value = 7;                       // Z2 x Z6 against Z3 x Z4

    function fingerprint(G) {
      var counts = {};
      G.elements().forEach(function (a) { var o = G.order(a); counts[o] = (counts[o] || 0) + 1; });
      var keys = Object.keys(counts).map(Number).sort(function (p, q) { return p - q; });
      return [
        String(G.n),
        G.isAbelian() ? 'yes' : 'no',
        G.isCyclic() ? 'yes' : 'no',
        keys.map(function (k) { return k + ':' + counts[k]; }).join(', '),
        String(G.elements().filter(function (a) { return G.op(a, a) === G.e; }).length)
      ];
    }
    var rowNames = ['order |G|', 'abelian?', 'cyclic?', 'elements of each order (order:count)', 'solutions of x² = e'];

    function drawFingerprints() {
      var L = groups[Number(selL.value)], R = groups[Number(selR.value)];
      var fl = fingerprint(L[1]), fr = fingerprint(R[1]);
      var body = rowNames.map(function (name, i) {
        var shade = fl[i] !== fr[i] ? 'background:#fbe0e0' : null;
        return A.h('tr', null, [
          A.h('th', { scope: 'row', text: name, style: shade }),
          A.h('td', { text: fl[i], style: shade }),
          A.h('td', { text: fr[i], style: shade })
        ]);
      });
      var div = document.getElementById('d17-fp');
      div.innerHTML = '';
      div.appendChild(A.h('table', { class: 'a308-cayley fp' }, [
        A.h('thead', null, [A.h('tr', null, [A.h('th', { class: 'corner', scope: 'col', text: 'invariant' }),
          A.h('th', { scope: 'col', text: L[0] }), A.h('th', { scope: 'col', text: R[0] })])]),
        A.h('tbody', null, body)
      ]));
      var differ = rowNames.filter(function (_, i) { return fl[i] !== fr[i]; });
      document.getElementById('d17-fp-out').innerHTML = differ.length
        ? '<strong>Not isomorphic.</strong> These rows differ: ' + differ.join('; ') + '.'
        : '<strong>Every row agrees.</strong> That is necessary for an isomorphism, but not enough. Look for the bijection that respects products.';
    }
    selL.addEventListener('change', drawFingerprints);
    selR.addEventListener('change', drawFingerprints);
    drawFingerprints();

    /* ---- Explore 2: candidate maps from D5 to itself ---- */
    var D5 = A.D(5), r = D5.index('r');
    var cands = [
      { name: 'x ↦ x (the identity)', f: function (x) { return x; } },
      { name: 'x ↦ x²', f: function (x) { return D5.op(x, x); } },
      { name: 'x ↦ e (every element goes to the identity)', f: function () { return D5.e; } },
      { name: 'x ↦ r·x (left multiplication by r)', f: function (x) { return D5.op(r, x); } }
    ];
    var selC = document.getElementById('d17-cand');
    cands.forEach(function (c, i) { selC.appendChild(A.h('option', { value: i, text: c.name })); });

    function testMap(f) {
      var img = D5.elements().map(f), bij = true, dup = null, hom = true, wit = null;
      var seen = {};
      img.forEach(function (y, x) { if (seen[y] !== undefined && bij) { bij = false; dup = [seen[y], x]; } seen[y] = x; });
      for (var a = 0; a < D5.n && hom; a++) for (var b = 0; b < D5.n; b++) {
        if (f(D5.op(a, b)) !== D5.op(f(a), f(b))) { hom = false; wit = [a, b]; break; }
      }
      return { img: img, bij: bij, dup: dup, hom: hom, wit: wit };
    }

    function drawMap() {
      var c = cands[Number(selC.value)], t = testMap(c.f);
      var head = A.h('tr', null, [A.h('th', { class: 'corner', scope: 'col', text: 'x' })].concat(D5.labels.map(function (lab) {
        return A.h('th', { scope: 'col', text: lab });
      })));
      var row = A.h('tr', null, [A.h('th', { scope: 'row', text: 'φ(x)' })].concat(t.img.map(function (y) {
        return A.h('td', { text: D5.labels[y] });
      })));
      var div = document.getElementById('d17-map');
      div.innerHTML = '';
      div.appendChild(A.h('table', { class: 'a308-cayley small' }, [A.h('thead', null, [head]), A.h('tbody', null, [row])]));
      var msg = '<strong>Bijective?</strong> ' + (t.bij ? 'yes.' : 'no: ' + D5.labels[t.dup[0]] + ' and ' + D5.labels[t.dup[1]] + ' both go to ' + D5.labels[t.img[t.dup[0]]] + '.') +
        '<br><strong>Respects products?</strong> ' + (t.hom ? 'yes.' : 'no: with x = ' + D5.labels[t.wit[0]] + ' and y = ' + D5.labels[t.wit[1]] +
          ', φ(x·y) = ' + D5.labels[t.img[D5.op(t.wit[0], t.wit[1])]] + ', but φ(x)·φ(y) = ' +
          D5.labels[D5.op(t.img[t.wit[0]], t.img[t.wit[1]])] + '.') +
        '<br><strong>' + (t.bij && t.hom ? 'An automorphism of D5: an isomorphism from D5 to itself.' : 'Not an isomorphism, so not an automorphism.') + '</strong>';
      document.getElementById('d17-map-out').innerHTML = msg;
    }
    selC.addEventListener('change', drawMap);
    drawMap();
  })();
</script>
