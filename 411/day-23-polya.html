How these work. Each walk-through takes one problem through Pólya’s four phases. You answer one step at a time and get feedback right away; when something isn’t right, read why and try again. Hints are there when you ask for them. Your place is saved in this browser, so you can stop and come back.

Naming \(\delta\), as on Day 22. Some steps ask you to type \(\delta\) as a formula in \(\varepsilon\) (type eps), and in some problems in \(a\) as well. The page then plays the opponent: it names challenges from \(\varepsilon = 10\) down to \(\varepsilon = 0.000001\), and for each one it hunts for an \(x\) within your \(\delta\) of \(a\) whose value lands outside the band around \(f(a)\). Any \(\delta\) that works is right, not only the one in the model proof. Passing is strong evidence, not a proof. If yours fails, you’ll see the challenge and the \(x\) that beat it.

Problem 8.1.17 asks for an argument from a unit circle. These walk-throughs describe the picture in words; they don’t draw it.

The walk-throughs end in full proofs, so the proof you bring to class should still be your own, in your own words.

Pólya walk-through · Problem 8.1.11

Smaller \(\delta\), larger \(\varepsilon\)

Problem 8.1.11. Given a particular \(\varepsilon>0\) in the definition of continuity, show that if a particular \(\delta_0>0\) satisfies the definition, then any \(\delta\) with \(0<\delta<\delta_0\) will also work for this \(\varepsilon\). Show that if a \(\delta\) can be found to satisfy the conditions of the definition of continuity for a particular \(\varepsilon_0>0\), then this \(\delta\) will also work for any \(\varepsilon\) with \(0<\varepsilon_0<\varepsilon\).

Goal: Prove two facts that explain why a proof only has to find one good \(\delta\), not the largest one. Each proof is a few lines, and each line has a reason. The reading says this after Example 8.1.10: “any smaller \(\delta\) would work as well.” This problem proves it, and part (b) gives the matching fact for larger \(\varepsilon\).

Pólya walk-through · Problem 8.1.12

Two sides, one \(\delta\)

Problem 8.1.12. Use the definition of continuity to show that \(f(x)= \begin{cases}\sqrt{x} & \text{ if } x\ge 0\\ -\sqrt{-x} & \text{ if } x< 0 \end{cases}\) is continuous at \(a=0\).

Goal: Find one \(\delta\) that works on both sides of \(0\) at once. First bound \(|f(x) - f(0)|\) on each piece, and see that the two pieces give the same bound. Example 8.1.10 proved that \(x^2\) is continuous at \(0\), with a \(\delta\) found from a square root. Here the function is a square root itself, so the proof runs the other way round.

Pólya walk-through · Problem 8.1.13

Only the right side counts

Problem 8.1.13. Use the definition of continuity to show that \(f(x)= \sqrt{x}\) is continuous at \(a=0\). How is this problem different from problem 8.1.12? How is it similar?

Goal: Prove that \(\sqrt{x}\) is continuous at \(0\), then compare the proof with 8.1.12: what changes when the function has values on only one side of \(0\). The reading’s paragraph after 8.1.11 restricts \(x\) to the domain of \(f\). This problem is where that matters, because \(\sqrt{x}\) has no values for \(x < 0\). Example 8.1.14 does \(\sqrt{x}\) at \(a = 1\), where the domain never comes up.

Pólya walk-through · Problem 8.1.16

Continuity away from zero

Problem 8.1.16. Use the definition of continuity to show that \(f(x)=\sqrt{x}\) is continuous at any positive real number \(a\).

Goal: For every \(a > 0\) and every \(\varepsilon > 0\), find a \(\delta\). The new move is the conjugate: multiply the difference by \(\frac{\sqrt{x} + \sqrt{a}}{\sqrt{x} + \sqrt{a}}\), then bound the denominator. Example 8.1.14 does \(\sqrt{x}\) at \(a = 1\), where \(\delta = \varepsilon\) happens to work. This problem asks for every positive \(a\), so the bound has to hold at small \(a\) as well.

Pólya walk-through · Problem 8.1.17

Sine, from a unit circle

Problem 8.1.17. Use a unit circle to show that for \(0\le\theta<\frac{\pi}{2}\), \(\sin \theta\le\theta\) and \(1-\cos \theta\le\theta\), and conclude that \(|\sin \theta|\le|\theta|\) and \(|1-\cos \theta|\le|\theta|\) for \(-\frac{\pi}{2}<\theta<\frac{\pi}{2}\). Use the definition of continuity to prove that \(f(x)=\sin x\) is continuous at any point \(a\). (Note: \(\sin x=\sin\left(x-a+a\right)\).)

Goal: Prove the two unit-circle inequalities, extend them to \(|\theta| < \frac{\pi}{2}\), and then use them to show that \(\sin x\) is continuous at every \(a\). This is the last problem of the day, so it ends in a full proof. Example 8.1.14 bounded \(|\sqrt{x} - 1|\) by a multiple of \(|x - 1|\). Here the bound is \(|\sin x - \sin a|\) by a multiple of \(|x - a|\), and the unit circle supplies the inequalities it needs.
